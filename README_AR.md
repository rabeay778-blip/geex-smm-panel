# GEEX SMM Panel — نسخة PostgreSQL

هذه نسخة تأسيسية معدلة لاستخدام PostgreSQL خارجي حتى لا تعتمد بيانات العملاء والطلبات على قرص مؤقت في الاستضافة.

## المزايا الحالية
- تسجيل حساب ودخول.
- خدمات تجريبية قابلة للإضافة من لوحة الإدارة.
- إنشاء طلب وخصم رصيده بمعاملة قاعدة بيانات.
- طلب شحن فودافون كاش ومراجعته واعتماد الرصيد من الإدارة.
- عرض الطلبات والعملاء وطلبات الشحن.
- نقطة اختبار API للمزود (لا تنفذ طلبات عند المزود بعد).

## متطلبات النشر
- استضافة Node.js تدعم Express.
- قاعدة PostgreSQL دائمة.
- متغيرات البيئة في `.env.example`.

## ملاحظات أمان وتشغيل
- غيّر كلمة مرور الإدارة و SESSION_SECRET قبل النشر.
- لا تضع مفاتيح المزود في ملفات الواجهة أو في المحادثة.
- أضف SMM_PROVIDER_URL و SMM_PROVIDER_KEY كـ Secrets في الاستضافة.
- يجب إضافة تكامل إرسال الطلبات الفعلي للمزود، والتحقق من رده، ومعالجة الفشل والاسترجاع قبل تشغيل الطلبات الحقيقية.
- يلزم إعداد مخزن جلسات دائم (مثل Redis أو PostgreSQL session store)، وHTTPS، وحدود لمحاولات الدخول، وسجل تدقيق ونسخ احتياطي قبل استقبال أموال حقيقية.
- رقم فودافون كاش الظاهر في الواجهة مأخوذ من بيانات إعداد المشروع، ويجب التأكد منه قبل النشر.
